# تیم‌ترکر

پنل مدیریت تسک برای تیم‌های کوچک. تیم‌لید تسک تعریف می‌کند، اعضا کارت‌هایشان را روی برد کانبان جابه‌جا می‌کنند، ساعت کارشان را ثبت می‌کنند و آخر کار تیک می‌زنند. تیم‌لید یا تأیید می‌کند تا تسک برای همیشه قفل شود، یا با ذکر دلیل برمی‌گرداند. همه‌ی تغییرها بدون رفرش برای بقیه‌ی تیم دیده می‌شود.

**دموی آنلاین:** https://teamtracker-s465.onrender.com — با `peyman` (تیم‌لید) یا `behnia` (عضو تیم) و رمز `1234` وارد شوید. سرور رایگان است و بار اول ممکن است تا یک دقیقه طول بکشد تا بالا بیاید؛ داده‌ها هر شب به حالت اول برمی‌گردند.

## امکانات

- برد کانبان چهارستونه با درگ‌اند‌دراپ برای تیم‌لید و اعضا (روی موبایل هم)
- تیک زدن عضو ← صف «منتظر تأیید» ← تأیید و قفل، یا برگشت با دلیل
- کشیدن کارت روی اسم یک نفر برای سپردن تسک به او
- تایمر روی کارت، ثبت دستی ساعت با تقویم شمسی، چک‌لیست هر تسک
- گفت‌وگو زیر هر تسک و مرکز اعلان‌ها
- داشبورد تیم‌لید: صف تأیید، وضعیت امروز، نقشه‌ی فعالیت ۶ هفته، ساعت این هفته در مقایسه با هفته‌ی قبل
- خروجی اکسل راست‌به‌چپ از ساعت کار
- مدیریت اعضا و پروفایل (تغییر نام و رمز)
- به‌روزرسانی زنده با SignalR، حالت تاریک، اعداد فارسی و تاریخ شمسی

## اجرا

پیش‌نیاز: .NET 8 SDK

</div>

```bash
dotnet run --project TeamTracker.csproj
```

<div dir="rtl">

بعد `http://localhost:5005` را باز کنید. بار اول دیتابیس SQLite با داده‌ی نمونه در `App_Data` ساخته می‌شود.
رمز همه‌ی حساب‌های نمونه `1234` است: `peyman` (تیم‌لید)، `behnia`، `mehrdad`، `mojtaba` و `hassan`.

برای دیدن حالت زنده، در یک پنجره با `behnia` و در یک پنجره‌ی ناشناس (Incognito) با `peyman` وارد شوید.

با Docker:

</div>

```bash
docker compose up --build
```
